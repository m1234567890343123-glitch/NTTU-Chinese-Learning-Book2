# 🐳 跟著小海學華語

這是以《來！學華語》第二冊第一課「今天天氣很好」的學習主題為參考，重新編寫的原創華語互動學習網站。

## 網站功能
- 天氣詞彙、拼音及瀏覽器語音播放
- 情境對話與三種句型
- 四題即時批改的互動選擇題
- 儲存在瀏覽器的學習進度與重新挑戰功能
- 適合電腦、手機的響應式設計

## 本機預覽
下載專案後，在瀏覽器開啟根目錄的 `index.html` 即可。

## 使用 Netlify 部署
1. 登入 https://app.netlify.com/。
2. 選擇 **Add new project / Import an existing project** → **GitHub**。
3. 授權並選擇 `m1234567890343123-glitch/NTTU-Chinese-Learning-Book2`。
4. **Branch** 設為 `main`，**Build command** 留空，**Publish directory** 填入 `.`。
5. 按 **Deploy**，取得公開的 `*.netlify.app` 網址。之後 GitHub main 分支更新可觸發重新部署。
